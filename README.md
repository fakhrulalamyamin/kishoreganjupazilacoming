## Webuzo প্যানেলে হোস্ট করার ধাপ
1. GitHub থেকে **Code → Download ZIP** দিয়ে ফাইলগুলো নামান।
2. Webuzo প্যানেলে লগইন করে **File Manager** খুলুন।
3. ডোমেইনের রুট ফোল্ডারে যান (সাধারণত `public_html` বা `/home/ইউজার/public_html/ডোমেইন`)।
   ভেতরে আগে থেকে থাকা `index.html`/`index.php` থাকলে মুছে দিন।
4. **Upload** দিয়ে ZIP ফাইলটি আপলোড করুন → ফাইলে রাইট-ক্লিক → **Extract**।
   নিশ্চিত হোন `index.html` সরাসরি রুট ফোল্ডারে আছে (কোনো সাব-ফোল্ডারের ভেতরে নয়)।
   *লুকানো ফাইল (`.htaccess`) দেখতে File Manager-এ "Show hidden files" চালু করুন।*
5. `data` ফোল্ডারের পারমিশন **755** রাখুন (PHP যেন সেখানে লিখতে পারে)।
6. **PHP সংস্করণ:** Webuzo → *Configuration → PHP / Default PHP Version* থেকে PHP **8.0 বা তার বেশি** নির্বাচন করুন।
7. **SSL:** Webuzo → *Security → SSL Certificate / Let's Encrypt* থেকে ফ্রি SSL ইনস্টল করুন।
   তারপর `.htaccess` ফাইলের HTTPS রিডাইরেক্টের ৩টি লাইনের সামনে থেকে `#` মুছে দিন।
8. ব্রাউজারে ডোমেইন খুলে দেখুন। 🎉
